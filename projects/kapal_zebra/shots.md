# kapal_zebra: rencana shot (1961 frame, 30 fps)

Tokoh: **Kapal zebra** (kapal dagang uap 1918, lambung belang hitam-putih-biru, cerobong belang, dasar merah). **Komandan = KAMU** (jas biru tua, topi putih, kancing emas, syal oranye-kuning di leher sebagai ciri khas lewat `band`). **Pelaut kapal zebra** (topi rajut warna-warni). **Dua anak** (analogi bola): bocah jaket hijau topi merah + anak perempuan kaus kuning.
Dunia: laut terbuka ke +x (pantai seberang dihapus), dermaga + kota di x < 0 (cuma untuk adegan bola). Kapal zebra berlayar di x = 200 ke arah -z. Kapal selam di (60, *, -60), sumbu z.
